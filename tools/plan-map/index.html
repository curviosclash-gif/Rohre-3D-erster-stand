startklar mit Risiko blockiert Dependency Kollision Impact

Status

startklar
Alle harten Startbedingungen sind erfuellt.
mit Risiko
Start ist moeglich, aber Soft-Gates oder Scope-Risiken sind sichtbar.
blockiert
Harte Dependency, Lock oder offener Vorblock verhindert Start.

Kanten

Dependency
Block braucht einen anderen Block oder eine Phase.
offen
Gestrichelte Kante markiert ein unerfuelltes Gate.
Kollision
Zwei Bloecke teilen Scope-Dateien.

Begriffe

Impact
Gewicht aus Scope-Groesse, Governance-Naehe und geteilten Dateien.
Consumer
Bloecke, die vom ausgewaehlten Block abhaengen.
Fokus
Auswahl, direkte Dependencies und Scope-Kollisionen bleiben prominent.
