- Desktop app is the primary product and source of truth for feature completeness.
- Online/browser build is a demo with intentionally reduced functionality unless user requests demo-specific work.
- Optimize UX, flows, and technical decisions for desktop first.
- Do not delay desktop improvements to preserve demo parity.
- Document intentional demo limitations in the relevant plan or docs update.
