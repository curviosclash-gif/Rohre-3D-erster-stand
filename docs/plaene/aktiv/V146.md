# Electron-Major-Security-Slice (V146)

Status: Aktiver Block im Master-Index.

## Intake-Zusammenfassung

V146 schliesst die letzte npm-seitige P21-Security-Ausnahme aus V90: die 10 Major-gebundenen
Befunde im Electron-Tree (`npm --prefix electron audit`, Stand 2026-06-11, alle high gerollt).
Die Wiedervorlage 2026-07-11 aus dem V90-Audit-Snapshot 2026-06-11 ist der Ziel-Termin fuer
diesen Block. Quelle der Befundlage: V90-Snapshot 2026-06-11 inkl. GHSA-Liste.

Die Reste zerfallen in zwei getrennt hebbare Pfade:

- `electron-builder@25.1.8` -> `electron-builder@26.15.2` (build-time): raeumt 9 der 10 Befunde,
  Wurzel ist die `tar`-Kette (6 high GHSAs, u. a. GHSA-34x7-hfp2-rc4v, GHSA-8qq5-rm4j-mr97) ueber
  `app-builder-lib`/`dmg-builder`/`node-gyp`/`cacache`/`make-fetch-happen`. Code wird nicht
  ausgeliefert; Risiko ist das Entpacken boesartiger Archive waehrend des Packagings.
- `electron@33.4.11` -> `electron@42.4.0` (runtime, 9 Major-Spruenge): raeumt 18 Shell-Advisories
  (high: GHSA-532v-xpq5-8h95, GHSA-8337-3p73-46f4, GHSA-jjp3-mq3x-295m, GHSA-9wfr-w7mm-pc7f).
  Exploit-Kontext ist die lokale Desktop-Shell ohne Remote-Content; deshalb P2 statt P1.

## Ziel

- Electron-Tree-Audit gruen oder auf dokumentierte, klein geschnittene Reste reduziert.
- P21 in `docs/prozess/Open_Findings.md` schliessen oder mit neuem, kleinerem Scope datieren.
- Build-time- und Runtime-Major getrennt heben, damit Rollback pro Pfad moeglich bleibt.

## Nicht-Ziel

- Kein gleichzeitiger Vite-7/8- oder Three-Sprung (eigene 90.3-Leitern).
- Keine Electron-API-/Feature-Arbeit ueber das Upgrade-Minimum hinaus.
- Keine Aenderung an `python/`-Manifesten (separater BT96-Block im Bot-Trainingsplan).

## Definition of Done

- [ ] DoD.1 `npm --prefix electron audit --audit-level=low` ist gruen oder jeder Restbefund ist mit GHSA, Exploit-Kontext und neuer Wiedervorlage dokumentiert.
- [ ] DoD.2 electron-builder- und electron-Major sind als getrennte Commits mit eigenen Gates gelandet (Rollback pro Pfad via `git revert`).
- [ ] DoD.3 Desktop-App startet und paketiert: `npm run build:app`, `npm run check:electron-renderer-drift`, `npm run test:desktop:smoke` PASS.
- [ ] DoD.4 P21-Status in `docs/prozess/Open_Findings.md` und V90-Snapshot-Folgeeintrag sind nachgezogen; `npm run docs:check` PASS.
