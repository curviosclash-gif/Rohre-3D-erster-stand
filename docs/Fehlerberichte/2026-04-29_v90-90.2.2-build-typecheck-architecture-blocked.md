- Datum: 2026-04-29
- Block: V90
- Phase: 90.2.2
- Status: offen

## Task-Kontext
Nach dem Fix der `core -> ui`-Boundary-Verletzungen sollte `npm run build` fuer den V90-Verifikationsschritt (`90.2.2`) erneut durchlaufen.

## Fehlerbild
`npm run build` passiert jetzt alle Architektur-Guards bis einschliesslich `check:architecture:metrics`, bricht aber bei `typecheck:architecture` mit einer grossen Menge TS-Fehlern ab.

## Reproduktion
1. `npm run build`
2. `prebuild` fuehrt `npm run architecture:guard` aus
3. `tsc -p tsconfig.architecture.json` liefert zahlreiche TS2322/TS2339/TS2345/TS2367-Fehler in mehreren bereits geaenderten Runtime-/Contract-Dateien
