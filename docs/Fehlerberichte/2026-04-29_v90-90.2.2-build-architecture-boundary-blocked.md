# Fehlerbericht: V90 90.2.2 Build-Gate durch Architektur-Boundary-Verletzungen ausserhalb des V90-Scope blockiert

- Datum: 2026-04-29
- Block: V90
- Phase: 90.2.2
- Status: geloest (2026-04-29)

## Task-Kontext
Fuer den ersten V90-Security-Slice sollten nach den nicht-breaking Dependency-Fixes (`npm audit fix` ohne `--force`) die nicht-testigen Verifikations-Gates (`npm run gates:pre-commit`, `npm run build`) gruensicher nachgezogen werden.

## Fehlerbild
`npm run gates:pre-commit` laeuft gruensicher, `npm run build` bricht aber im `prebuild`-Pfad ab (`architecture:guard` -> `check:architecture:boundaries`), weil aktuell geaenderte Core-Dateien direkte UI-Imports enthalten.

Fehlerauszug:
- `Architecture boundary guard failed.`
- `core -> ui import @ src/core/AppInitializer.js:57`
- `core -> ui import @ src/core/TestApiBridge.js:27`

## Reproduktion
1. `npm run build`
2. Build laeuft im `prebuild` auf `npm run architecture:guard`
3. `npm run check:architecture:boundaries` meldet acht `core -> ui`-Imports in `src/core/AppInitializer.js` und `src/core/TestApiBridge.js`

## Betroffene Dateien
- `src/core/AppInitializer.js` (nicht Teil des V90-Zielscope)
- `src/core/TestApiBridge.js` (nicht Teil des V90-Zielscope)

## Bereits durchgefuehrte Schritte
- `npm audit --audit-level=low`, `npm outdated`, `npm --prefix electron audit --audit-level=low`, `npm --prefix electron outdated`, `npm --prefix server audit --audit-level=low`, `npm --prefix server outdated` -> V90-Matrix erhoben
- `npm audit fix` -> Root auf 2 moderate Restbefunde reduziert (`esbuild`/`vite`)
- `npm --prefix electron audit fix` -> Electron auf 12 verbleibende High/Low-Befunde reduziert
- `npm run graph:build` -> Wissensgraph mit aktuellem Worktree synchronisiert
- `npm run gates:pre-commit` -> PASS
- `npm run build` -> reproduzierbarer Architektur-Guard-Blocker

## Aktueller Status
Der Boundary-Blocker ist behoben: direkte `core -> ui`-Referenzen in der Test-API-Verdrahtung wurden entfernt, `npm run check:architecture:boundaries` laeuft wieder gruen.

## Naechster Schritt
Build erneut laufen lassen und verbleibende Guard-/Typecheck-Blocker separat erfassen.
