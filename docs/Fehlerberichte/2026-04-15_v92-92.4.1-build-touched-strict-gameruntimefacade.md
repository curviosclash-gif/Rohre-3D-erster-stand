- `npm run plan:check`, `npm run docs:sync` und `npm run docs:check` laufen gruensicher.
- `npm run build` bricht bereits im `prebuild`-Schritt `npm run architecture:guard` ab.

  - `src/core/GameRuntimeFacade.js: 505 lines exceeds touched baseline 493 + budget 8 (legacy 470)`

1. `npm run build`
2. `prebuild` startet `npm run architecture:guard`
3. `npm run check:eslint:touched-strict` failt mit der Baseline-Ueberschreitung in `src/core/GameRuntimeFacade.js`
